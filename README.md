# Simprove

Your digital golf coach. Track, analyze, and improve your swing using simulator data.

## About
Simprove lets golfers import data from their launch monitor, track stats over time, 
and get AI-powered lesson recommendations based on their performance.

## Tech Stack
- Next.js
- TypeScript
- SCSS
- Supabase (PostgreSQL)
- Claude API (AI lesson recommendations)

## Features
- Import and track golf simulator data
- Performance analytics and stat tracking
- AI-powered lesson recommendations
- User profiles with handicap tracking
